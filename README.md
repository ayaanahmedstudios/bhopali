# Bhopali Typeface

Bhopali is a custom typeface designed by Ayaan Ahmed (Ayaan Letterforms) in 2026[cite: 2]. 

🌐 **[Visit the Bhopali Website](https://ayaanahmedstudios.github.io/bhopali/index.html)** to test the font, view its features, and learn more about its background.

## Download

To install the font, download **Bhopali.zip** from this repository.
